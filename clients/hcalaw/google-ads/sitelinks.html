The rule that disapproves more sitelinks than anything else

Two sitelinks in the same set may not point to the same page. Not the same page with a different anchor, not the same page with a tracking parameter — a genuinely different destination. When a firm doesn’t have enough pages, the usual improvisation is to aim three or four sitelinks at the homepage, and Google disapproves the whole set.

So this document is really two deliverables: the copy below, and a short list of pages the site needs before most of that copy can run.

Getting them wrong

  • NO
    Several sitelinks to the homepageThe most common disapproval. If the pages don’t exist yet, run fewer sitelinks — two real ones beat six that get the set rejected.
  • NO
    A sitelink matching the ad’s own final URLNot disapproved, but wasted. The searcher already has that link; the sitelink slot should offer somewhere new.
  • NO
    Off-domain destinationsA sitelink pointing at a directory profile, a review site, or a social page will be rejected. Same domain as the ad.
  • NO
    One description line filled, the other blankDescriptions render as a pair or not at all. Half a pair simply never shows.
  • NO
    Calls to action as link text“Call Now” wastes the slot. A sitelink is a destination, so name the destination — the click is already the action.
  • NO
    Pages that 404 or redirectChecked at review and rechecked periodically. A slug that changes during a site update silently kills the sitelink.
