Two Headers, Eighteen Values

How to set up structured snippets for the hcalaw.net criminal defense campaign. Unlike callouts, you don't write the label — you pick one of Google's thirteen fixed headers, and only two of them fit a law firm. Everything below is verified against the 25-character value limit and deconflicted against the callout set.

Step 1 — Pick the header

That mismatch invites disapproval, and service-area coverage is better carried by location assets and the geo callouts already in the set.

Step 2 — Load the values

Run Types as the primary. It reads as a list of charges the firm defends, which is exactly what someone facing one is scanning for, and its noun-form values never collide with the callouts, which are all "X Defense" phrases.

What it looks like in the auction

Callouts and structured snippets can appear in the same ad, which is the whole reason the two lists were deconflicted. The snippet renders as the header, a colon, then as many values as fit the width:

Step 3 — Choose the level

Snippets inherit downward, and the most specific level wins. Set them where the intent is:

LevelWhat to put thereWhy
Account Service catalog — all 8 values A safety net so every campaign has a snippet, including any built later.
Campaign Types — all 10 values The primary. Broad enough to be true of the whole criminal-defense campaign.
Ad group Types — the 3–5 that match the keywords In the DWI ad group, lead with DWI & DUI, Underage Drinking, Misdemeanors. Relevance beats volume: an override at this level replaces the campaign list rather than adding to it.

Because an ad-group list overrides the campaign list entirely, never set fewer than three values at that level — a two-value override silently stops snippets from serving in that ad group.

Verify before launch

Two values sit slightly outside what the firm's public record documents. Both are ordinary criminal-defense work and probably fine, but a snippet value is a claim about what the firm handles.

    Probation ViolationsStandard criminal-defense work and a reasonable inference, but not named in the firm's directory listings. Confirm they take these.
  • VERIFY
    Underage DrinkingPlausible near a university town, and it pairs well with the DWI ad group. Confirm before running it.
  • VERIFY
    Sex CrimesDocumented in the firm's practice areas, so the claim is sound — but sensitive-category values can serve unevenly. Watch impressions and pull it if it drags the header's delivery.

What breaks a snippet

Snippets are policed harder than callouts, because the header sets an expectation about what the list contains. Each of these is a disapproval or a wasted slot.

  • NO
    Free ConsultationA benefit, not a type or a service. Values that don't fit the header get the whole snippet disapproved — this belongs in the callouts, where it already is.
  • NO
    Call Us TodayStructured snippets are not clickable and take no CTAs. Same rule as callouts.
  • NO
    Aggressive DefenseAn adjective, not a category member. Snippet values must be things you could put in a list, not descriptions of how you work.
  • NO
    DWI SpecialistNC Rule 7.4 restricts specialist claims to NC State Bar certified lawyers. Listing a field of practice is fine; claiming specialization is not.
  • NO
    Only 2 valuesBelow three, the header will not serve at all. Ten is the ceiling.

Why this is the safest asset type for a law firm

North Carolina Rule 7.4 expressly permits a lawyer to communicate the fields of law in which they practice — it restricts only the word "specialist" and its equivalents. A structured snippet under Types is nothing but a list of practice fields, which is why it carries less bar-advertising exposure than almost anything else you can attach to the ad. Keep the values as plain category nouns and there is nothing in them to substantiate.
